## Durable order

`validated evidence → validated/O_EXCL reassignment artifact → digest-bound ATTEMPT_FINISHED → refold → maintenance/selection → reconciliation artifact/event → result`.

Crash resumption authenticates an identical existing artifact; a conflicting artifact or changed preserved evidence fails closed. No `RUN_ENDED` event is introduced.
