## Anti-Patterns Verdict

**LLM assessment**: Largely avoids AI slop. Floating panel layout, time-aware greeting, domain-specific suggestion chips, and purposeful scroll-fade gradient all show considered design. Main tells: mobile top bar has no app identity; empty mobile state has no guidance.

**Deterministic scan**: Detector returned [] — clean. Issues are architectural (conditional rendering, missing tokens in className, missing a11y attributes).

## Overall Impression

Sound product decisions throughout — sidebar, floating panel, citation→source panel flow, time-aware greeting. The two biggest problems are both mobile-specific. Mobile first-timers get a blank input with no suggestions and a hamburger in an unusual position with no accessible label. For a theological research tool used in churches (mobile-heavy audience), this mobile first impression is the highest-priority fix.

## What's Working

1. **Time-aware greeting** — "You're up late. What would you like to explore?" is genuine personality. Contextual, signals someone thought about when theological study actually happens.
2. **Floating panel architecture** — bg-sidebar canvas + rounded bg-background panel creates depth without glass effects. h-dvh-safe + overflow-hidden on root prevents iOS scroll-bounce.
3. **Citation-to-source-panel pattern** — Right pattern for a scholarly tool. Seeing source context in a slide-in panel differentiates Rhemata from generic chatbots.

## Priority Issues

**[P1] Mobile empty state gives first-timers nothing to do**
The three suggestion chips are hidden on mobile (`!isMobile` guard). Mobile first-timers see a greeting and blank input with no indication of what to ask.
Fix: Show suggestions on mobile as stacked full-width buttons. Show 2 instead of 3 on small screens.
Command: /impeccable adapt

**[P2] Mobile hamburger is on the right, missing aria-label, inconsistent with other pages**
Home page: hamburger right. Authors page: hamburger left (with aria-label). Different conventions for the same action.
Fix: Add aria-label="Open sidebar". Restructure top bar to hamburger-left pattern.
Command: /impeccable polish

**[P2] text-red-400 breaks design token contract in two places**
Lines 191 and 234 use text-red-400 instead of text-destructive. Also missing role="alert" and aria-live="polite" on error paragraphs.
Fix: Change both to text-destructive. Add role="alert" aria-live="polite".
Command: /impeccable polish

**[P2] Greeting h2 missing text-balance**
"Good morning, what would you like to learn about?" can break to a single orphaned word. DESIGN.md mandates text-balance on h1-h3.
Fix: Add text-balance to h2 className.
Command: /impeccable polish

**[P3] No / keyboard shortcut to focus chat input**
Library page wires / keydown to focus search. This page — primary interaction surface — has no such shortcut.
Fix: Add useEffect for / keydown gated on active element not being an input. Same pattern as library page.
Command: /impeccable polish
